The Ilé Design System

A banking-grade visual language for renting, buying & selling property in Nigeria — where verification, escrow and trust are primary content, never decoration.

Forest Trust Green Hanken Grotesk + IBM Plex Mono 8pt grid Loading · Empty · Error · Success
Foundations

Color

Forest green carries trust and security. Warm, low-chroma neutrals keep data-dense dashboards calm. Semantic colors stay visually distinct from the brand so status is never ambiguous. Click any swatch to copy its token.

Foundations

Typography

Hanken Grotesk for everything UI — legible, friendly, dense-friendly. IBM Plex Mono for money, escrow figures and IDs so numbers read as precise, tabular data.

Foundations

Spacing, Grid & Shape

An 8-point base scale (with a 4px half-step) governs all rhythm. Radii and shadows are deliberately soft and warm-tinted.

Iconography

Outlined, single-weight (1.75px stroke), rounded joins. Consistent 24px grid. Used for navigation, specs and status — never for decoration.
